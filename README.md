# Wang Chenrui Resume Website

A bilingual personal resume website for Wang Chenrui, built with plain HTML, CSS, and JavaScript.

## Features

- Chinese and English interface toggle
- Resume-style single-page layout
- SimSun-style Chinese typography and Georgia English typography
- Education, internships, projects, skills, and honors
- Portrait included locally as `portrait.jpg`

## Publish

This repository is configured for GitHub Pages. In the repository settings, select **Pages**, then deploy from the `main` branch and the root folder. The published site will be available at:

https://cherrywang0327.github.io
